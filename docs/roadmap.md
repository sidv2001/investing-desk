# Roadmap, with explicit boundaries

**Now — runnable public starter.** Python 3.12 and standard-library-only
runtime; two local fictional scenarios; timestamp-checked, cited one-page
memos from bounded read-only workers; explicit human approve/reject/defer of a
hashed, expiring PAPER proposal; risk- and cost-bounded SQLite entries;
manual invented-price monitoring; retrospectives that surface the original
catalyst and countercase. The live-order adapter only raises. No market feed,
LLM call, broker, order client, or background watcher exists.

**Next — research quality, subject to data rights.** Evaluate legally usable
sources and their AI/redistribution terms before connecting them. Preserve
publication, availability, revision, and as-of times; test missing and
contradictory evidence. If agent analysts are introduced, keep cited outputs
bounded, reproducible where possible, and unable to approve decisions. Improve
the human review view without replacing the countercase.

**Then — more credible paper evaluation.** Add licensed point-in-time data
only after permission checks. Model spreads, fees, splits, dividends, partial
fills, and delayed data; compare across out-of-sample periods and explain
failed theses. Any paper-broker connection would be a separate reviewed
integration, not an automatic upgrade of the local ledger. Monitoring could
later become scheduled, with explicit staleness and missing-data alerts.

**Separately authorized future — real money.** Only a new, deliberate phase
could consider brokerage credentials and order submission. It would require
identity-bound human authorization, independent hard risk limits, test and
reconciliation evidence, audit trails, failure handling, a kill switch, and
applicable legal/compliance review. The current scaffold cannot be enabled by
an environment variable or configuration change. No returns or timeline are
promised.
